# Compare results and choose the next analysis

Use the atlas to compare selected targets, binding sites, or candidates for a
specific research purpose. Ask Codex to connect the comparison to the next
measurement and preserve your selected records in plugin requests.

```text
Use my Surface Atlas to compare [TARGETS, SITES, OR CANDIDATES] for
[INTENDED ACTION]. Show the relevant measurements, sources, conditions, and
controls. Explain which findings favor each option and which missing
measurement could change the choice. Suggest the corresponding Rosalind
Workbench recipe, including its inputs and expected output. Use my existing
scope and budget for any work you carry out.
```

Life Sciences Databases and Life Sciences Literature can fill gaps in source
evidence. NGS Analysis Workbench can analyze selected sequencing datasets.
Use the sequence and structure viewers to inspect constructs and contact
residues. Use Adaptyv Bio to prepare a supported assay when the next step
requires experimental measurements.

## Build views for the comparison

Start with the installed **Compare actions** and **Sequence & sites** pages.
Populate [action evidence](../action-comparison.md) and
[verified sequence maps](../sequence-sites.md), then rebuild the report. The
views already provide action switching, source-based criteria, next
measurements, sequence-range downloads, and portable requests. Legacy records
without these extensions remain explicitly unmeasured or unavailable.

```text
Extend this report with the views needed for [RESEARCH PURPOSE]. Open each
page with its main finding and a useful action. Connect the selected protein
sequence, annotated regions, binding-site contacts, and 3D structure where
the records provide verified residue mappings. Include range downloads and
Codex requests that preserve the selection and name the required files.
Use an independent reviewer to check filters, residue links, downloads, and
copied requests against the source records.
```

Use custom extensions when the built-in views do not answer your project question. Read
the [reader workflow guide](../../skills/codex-surface-targets/references/reader-workflow.md)
for comparison, selection, and review requirements. Use
[Sequences, structures, and sites](sequences-structures-sites.md) to prepare
the molecular records, or [Experiments and report](experiments-and-report.md)
to add returned measurements. To host the result, follow
[Publish a report as a ChatGPT Site](chatgpt-site.md).
